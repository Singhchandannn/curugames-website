FOR PARENTS

Parents choose the catalog. Kids get a focused game space.

Parent Control is designed to keep the app familiar while letting a parent decide which games are available in Kids Mode.

Parent setup requires a signed-in account

A signed-in parent opens Parent Control from Settings, unlocks the protected area, chooses the games they want and turns Kids Mode on.

Choose built-in and Pro Games visually

The game picker uses the actual game catalog with Built-in and Pro tabs, search and selection states. Parents can browse the games before deciding what is visible.

PIN and supported biometrics

A parent can use a Parent PIN and, on supported enrolled devices, biometric unlock. Protected actions can show a lock while normal content remains visible.

Kids Mode does not make the app empty

Gameplay remains available for parent-selected games. Normal informational areas such as Events and The Curu Shop can remain visible, while protected account or reward actions can require parent unlock.

Local-device control

The Parent Control configuration is stored locally on the device and is excluded from Android backup/transfer in the current app design. Uninstalling the app resets that local Parent Control state.

Kids Mode is not a separate child account

Kids Mode is a parental-control experience inside the signed-in Curu account. It does not by itself create a new child account or separate identity.
